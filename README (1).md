# Personal Introduction Page 🚀

A responsive personal introduction webpage that showcases who you are while demonstrating proficiency in HTML, CSS, and JavaScript.

**Live Demo:** [View the Website](https://nikhilbalasundaram.github.io/NCC-Recruitment-Tasks-2-1st-Year-Technical-Domain-/)

---

## Overview

This project is a modern, interactive personal portfolio webpage designed to introduce yourself to potential employers, collaborators, or anyone interested in learning about you. The page is fully responsive and works seamlessly across desktop and mobile devices.

---

## Features Implemented ✨

### Core Features
- **Responsive Design** - Adapts perfectly to desktop, tablet, and mobile devices using CSS media queries
- **Personal Information Section** - Displays your name, photograph, and introduction
- **About Section** - Detailed description of who you are and your background
- **Skills & Interests** - Showcase your hobbies, skills, and interests in an organized layout
- **Social Links** - Links to your social media profiles and contact information (optional)
- **Clean UI** - Professional and attractive user interface with smooth interactions

### Brownie Subtask ⭐
- **Dark/Light Mode Toggle** - Switch between dark and light themes for better accessibility and user preference
- **localStorage Integration** - Your theme preference persists across page refreshes

## How to Run 🚀

### Option 1: View Live
Simply visit the live link:
```
https://nikhilbalasundaram.github.io/NCC-Recruitment-Tasks-2-1st-Year-Technical-Domain-/
```

### Option 2: Run Locally
1. **Clone the repository**
   ```bash
   git clone https://github.com/nikhilbalasundaram/NCC-Recruitment-Tasks-2-1st-Year-Technical-Domain-.git
   cd NCC-Recruitment-Tasks-2-1st-Year-Technical-Domain-
   ```

2. **Open in browser**
   - Double-click `index.html`, OR
   - Use a local server:
     ```bash
     # Python 3
     python -m http.server 8000
     
     # Python 2
     python -m SimpleHTTPServer 8000
     
     # Node.js (if installed)
     npx http-server
     ```
   - Then open `http://localhost:8000` in your browser

## Troubleshooting 🔧

### Theme not persisting?
- Check if localStorage is enabled in your browser
- Clear browser cache and try again

### Images not showing?
- Ensure image paths are correct relative to `index.html`
- Check image formats are supported (JPG, PNG, WebP)

### Responsive design not working?
- Verify viewport meta tag is in `<head>`:
  ```html
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  ```
- Test in browser DevTools (F12) → Device Toolbar
